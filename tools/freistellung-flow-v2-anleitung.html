Flow v2

Genehmigen in Teams – Logik sauber trennen

Liste und Audit-Spalten legt das Setup-Tool an. Diese Anleitung beschreibt den Flow in Power Automate. Nach dem Export kommt das ZIP zurück ins Projekt.

Langsam bauen? Modul für Modul: docs/freistellung-flow-v2-langsam.md – heute nur Modul 1, dann weiter wenn du bereit bist.

Regeln (fachlich)

  • KV-E-Mail = Direktion → eine Genehmigung an die Sonderperson (Setup: Sondergenehmigung).
  • 1 Kalendertag (Beginn = Ende, inkl. Zählung = 1) → nur Klassenvorstand.
  • Ab 2 Tagen → Sequential: Klassenvorstand, dann Direktion.
  • Nach jeder Entscheidung: Status in der Liste, Audit-Spalten, Mail aus freigegebenem Postfach.

Audit-Spalten (vom Setup ergänzt)

Flow v2 befüllt diese Felder – der Planer zeigt sie in Detail & CSV.

  • GenehmigtVonKV, GenehmigtAmKV
  • GenehmigtVonDirektion, GenehmigtAmDirektion
  • AbgelehntVon, AbgelehntAm
  • Bemerkungen – Approval-Kommentare (wie bisher)

Designer-Struktur (empfohlen)

  1. Trigger: Wenn ein Element erstellt wird (SharePoint, Ihre Freistellungsliste).
  2. Variable: Array für Kommentare (optional).
  3. Compose KvEmail: toLower(triggerBody()?['Klassenvorstand/Email'])
  4. Compose TageAnzahl: inklusive Kalendertage zwischen Beginn und Ende (siehe Markdown-Datei im Repo für Formel).
  5. Bedingung A: KvEmail gleich Direktion (E-Mail aus Setup / Umgebungsvariable FR_EmailDirektion)
    • Ja: Approvals Basic → Sonderperson → Status + Audit + Mail → Beenden
    • Nein: Bedingung B: TageAnzahl < 2?
      • Ja: Approvals Basic → KV
      • Nein: Approvals Sequential → KV, dann Direktion
  6. Bei Sequential: Schleife über responses, Kommentare sammeln; KV/Direktion aus Antwort 1 und 2 in Audit-Spalten schreiben.

Beispiel: Genehmiger aus Approval (Basic)

In „Element aktualisieren“ → Spalte GenehmigtVonKV:

@{concat( outputs('Genehmigung_KV')?['body/responses'][0]['responder/displayName'], ' <', outputs('Genehmigung_KV')?['body/responses'][0]['responder/email'], '>' )}

Aktionsnamen (Genehmigung_KV) an Ihre Bezeichnung anpassen.

Copilot in Power Automate

Prompts zum Kopieren – am besten 4 Schritte nacheinander, nicht alles auf einmal.

Realistisch: Copilot baut Trigger, Bedingungen und Genehmigungen grob richtig. Sequential Approvals, Audit-Spalten und „Beenden“ im Sonderfall prüfst du danach manuell (Checkliste in der Markdown-Datei).

Vollständige Texte: docs/freistellung-flow-v2-copilot.md im Repository. Vor dem Einfügen direktion@…, vertretung@…, automate@… durch echte Adressen ersetzen.

Prompt 1 – Trigger & Tageszahl (in Copilot einfügen)
Erstelle einen automatisierten Cloud-Flow für eine Schule (Österreich, Deutsch). Trigger: Wenn ein Element in einer SharePoint-Liste erstellt wird. Liste: Freistellungen (Site und Liste wähle ich im Trigger). Spalten: Beginn, Ende, Status (Ausstehend|Genehmigt|Abgelehnt), Klasse, Klassenvorstand (Person), Kategorie, Beschreibung, Bemerkungen, GenehmigtVonKV, GenehmigtAmKV, GenehmigtVonDirektion, GenehmigtAmDirektion, AbgelehntVon, AbgelehntAm. Nach dem Trigger: Array-Variable KommentareGenehmigung; Compose KvEmail = toLower(Klassenvorstand Email); Compose TageAnzahl = inklusive Kalendertage zwischen Beginn und Ende (gleicher Tag = 1). Noch keine Genehmigung.
Prompt 2 – KV = Direktion (Sonderfall)
Bedingung KvIstDirektion: KvEmail gleich direktion@schule.at (ich passe an). Wenn ja: Approvals Basic an vertretung@schule.at, Details mit Autor, Klasse, Beginn, Ende, Kategorie, Beschreibung, Link. Bei Approve: Status Genehmigt, GenehmigtVonKV/GenehmigtAmKV aus Approval, Bemerkungen = Kommentar. Bei Ablehnung: Status Abgelehnt, AbgelehntVon/AbgelehntAm. Mail aus freigegebenem Postfach automate@schule.at an Autor. Danach Beenden (Succeeded). False-Zweig leer.
Prompt 3 – 1 Tag vs. mehrtägig
Im False-Zweig: Bedingung Mehrtaegig wenn TageAnzahl >= 2. Wenn < 2: Approvals Basic an Klassenvorstand Email; Audit nur KV; Mail an Autor. Wenn >= 2: Approvals Sequential Schritt1 Klassenvorstand Email, Schritt2 direktion@schule.at; bei Erfolg beide Audit-Paare + Kommentare in Bemerkungen; bei Ablehnung AbgelehntVon/Am; Mail an Autor.
Prompt 4 – Nachbesserung
Title nicht ändern. Status exakt Genehmigt/Abgelehnt. Keine doppelte Mail. Nach Sonderfall-Zweig muss Beenden greifen. Kurz auf Deutsch zusammenfassen welche Bedingungen es gibt.

Export ins MS365-Schul-Tools-Projekt

  1. Power Automate → Flow → Exportieren → Package (Legacy).
  2. ZIP unter assets/power-automate/freistellung/ einspielen (Ordner-GUID beachten).
  3. In freistellung-setup.js die Platzhalter SOURCE (Site, Liste, E-Mails) auf die Werte im Export anpassen.
  4. Setup-Tool: Paket testen, an Test-Tenant importieren.
