Phase 3 – Flow-Paket & Import

ZIP herunterladen, dann die Klicks unten – ohne Fachchinesisch.

Power Automate öffnen
  1. In Power Automate links Meine Flows öffnen.
  2. Oben Importieren → Import Package (Legacy) wählen.
  3. Das eben heruntergeladene ZIP hochladen.
  4. Bei jeder Connection (SharePoint, Approvals, Outlook): Auswählen → Konto der Schule verbinden (oder vorhandene Connection).
  5. Import abschließen, den Flow öffnen und Einschalten (Toggle).
  6. Test: in der Freistellungsliste ein Testelement anlegen und die Genehmigung prüfen.

Später (wenn ihr Solutions nutzt): derselbe Ablauf, nur über Solutions → Importieren und dann Environment Variables setzen. Für den Start reicht das Legacy-Paket aus diesem Tool.

Was der Flow macht

Kurz zur Kontrolle – Details ändern sich nur über die E-Mails oben.

  • Trigger: neues Element in der Freistellungsliste.
  • Wenn Klassenvorstand = Direktion → nur Sondergenehmigung (eine Person).
  • Sonst sequentiell: Klassenvorstand, dann Direktion.
  • Status in SharePoint + Mail aus dem freigegebenen Postfach.
