Genehmigung & Flow

Genehmiger, Technik-Konto für Power Automate und Absender der Status-Mails.

Mit diesem Konto in Power Automate anmelden, Flow importieren und alle Connections (SharePoint, Approvals, Outlook) verbinden – nicht mit einem persönlichen Lehrer-/IT-Konto.

Nur bei separatem freigegebenen Postfach Haken entfernen; dann braucht das Technik-Konto „Senden als“ auf diese Adresse.

          Protokoll

          Flow-Paket & Import

          ZIP herunterladen und in Power Automate importieren – Schritte unten.

          Flow v2 bauen (Anleitung) Power Automate öffnen

          Das Paket basiert auf Flow v2 (sequentielle Genehmigung KV → Direktion, Audit-Spalten, Mehrtages-Logik). Site, Listen-ID, Genehmiger, Absender und Technik-Konto kommen aus Schritt 2.

          Technik-Konto aus Schritt 2: …

          1. Browser abmelden oder privates Fenster – in Power Automate mit dem Technik-Konto anmelden (nicht mit einem persönlichen Konto).
          2. Links Meine Flows öffnen.
          3. Oben Importieren → Import Package (Legacy) wählen.
          4. Das eben heruntergeladene ZIP hochladen.
          5. Bei jeder Connection (SharePoint, Approvals, Outlook): Auswählen → mit dem Technik-Konto verbinden (alle drei dieselbe Anmeldung).
          6. Import abschließen, den Flow öffnen und Einschalten (Toggle).
          7. Test: in der Freistellungsliste ein Testelement anlegen und die Genehmigung prüfen.

          Später (wenn ihr Solutions nutzt): derselbe Ablauf, nur über Solutions → Importieren und dann Environment Variables setzen. Für den Start reicht das Legacy-Paket aus diesem Tool.

          Was der Flow macht
          • Trigger: neues Element in der Freistellungsliste (Polling, typisch wenige Minuten).
          • Wenn Klassenvorstand-E-Mail = Direktion (Setup) → eine Genehmigung an die Sonderperson (Setup).
          • Sonst sequentiell Klassenvorstand → Direktion (inkl. Mehrtages-/Audit-Logik v2).
          • Status in SharePoint + Status-Mail an den Antragsteller (Absender = Technik-Konto bzw. konfiguriertes Postfach).
