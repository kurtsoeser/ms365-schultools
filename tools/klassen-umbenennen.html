Dashboard Klassen in Stammdaten

Klassen-Gruppen: Anzeigename nach Schuljahreswechsel

Dieses Werkzeug ist bewusst von den Stammdaten getrennt. Die Klassenlisten pflegen Sie weiterhin unter Stammdaten → Klassen; hier geht es nur um den Wechsel der Anzeigenamen in Microsoft 365.

Stabile Gruppen-E-Mails bzw. Mail-Aliase bleiben gleich. Geändert wird lokal und optional in Microsoft 365 nur der Anzeigename. Voraussetzung für das Schreiben nach Microsoft 365: Anmeldung über das Widget oben und vorhandene graphGroupId-Einträge aus der Einrichtung.
