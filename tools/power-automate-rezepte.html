1. Schultermine → Outlook-Kalender

Liste „Schultermine“ → Event im Schul- und/oder Lehrerkalender; SyncStatus setzen.

  1. Trigger: Wenn ein Element erstellt/geändert wird (SharePoint).
  2. Bedingung: SyncStatus = pending oder leer.
  3. Aktion: Ereignis erstellen (Outlook) – ganztägig aus AllDay, sonst Beginn/Ende.
  4. OutlookEventID + SyncStatus=ok + LastSync speichern; bei Fehler SyncError füllen.
  5. Optional zweite Verzweigung für Ziel „Lehrer“ (eigene Mailbox/Gruppe).
Schultermine-Tool

2. Forms → SharePoint-Liste (Anträge)

Raumanträge, Exkursionen, Geräte – statt E-Mail-Chaos.

  1. Microsoft Forms für den Antrag anlegen.
  2. Flow: Bei neuer Antwort → Element in Liste „Anträge“ anlegen.
  3. Genehmigung (Approve/Reject) an Direktion/Verwaltung.
  4. Bei Genehmigung: optional Kalendereintrag oder Team-Nachricht.

3. Seminar-/Fortbildungsliste

Anmeldung → Warteliste → Bestätigung an Lehrkraft.

  1. Liste oder Forms als Anmeldeque.
  2. Flow zählt Plätze; bei Überbuchung Status „Warteliste“.
  3. E-Mail an Teilnehmer:in + optional Adaptive Card in Teams.

4. Gast-Erinnerung (Hygiene)

Periodisch Gäste ohne Aktivität melden – ergänzt das Gäste-Tool.

  1. Geplanter Flow (z. B. monatlich).
  2. Graph/Office 365: Gäste auflisten (oder CSV aus dem Tool importieren).
  3. E-Mail an IT mit Liste „prüfen/löschen“.
Gäste-Tool

5. Diplomarbeit: Ordnerstruktur nach Anlage

Wenn ein Team mit Alias dipl-* entsteht – Vorlagenordner anlegen.

  1. Trigger: Team erstellt (oder manuell mit Gruppen-ID).
  2. Bedingung: mailNickname beginnt mit dipl-.
  3. Ordner anlegen: Exposé, Rohdaten, Abgabe, Feedback.
  4. Willkommensnachricht im General-Kanal.
Diplomarbeiten-Tool

6. Schilf: Kalender abonnieren (Checkliste)

Kein Flow – Prozess für Lehrkräfte nach Fortbildung.

  1. Outlook / Teams: Kalender hinzufügen → aus Verzeichnis (Schulkalender).
  2. Favoriten: Intranet, Formulare, Lehrerliste pinnen.
  3. Zielgruppen: öffentliche News vs. Kollegiums-Kanal trennen.
