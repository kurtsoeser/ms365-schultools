Als Hub-Website registrieren

Macht die Site zum Navigations-Hub. Im Browser oft blockiert (CORS) – dann PowerShell oder Admin Center.

Empfohlen, wenn der Browser scheitert: SharePoint Admin Center – Aktive Sites → Site wählen → Hub → Als Hub-Website registrieren (SharePoint-Admin-Recht nötig).

PowerShell (zuverlässig)

Skript kopieren, PowerShell als Admin-Benutzer ausführen. Danach ist die Intranet-Site ein Hub.
